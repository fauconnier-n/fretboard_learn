          Fretboard

          Sharp/flat notes are asked randomly as either name (A# or Bb), and each name is learnt separately. Progress is stored per tuning.

          Practice

          The answer is shown after about 2.5× your usual time for that note (4–8 s), or after this limit if it is shorter. Showing it counts as a miss.

          Optional. A concrete "when, where, what" plan is shown before each run; plans like this make people more likely to follow through.

          Fade shows a name where you are still unsure, drops it once you answer that note right, and brings it back after a miss. A right answer with its own name showing counts only as Hard and its time is not used for speed. Check-up prompts (every 10th) and re-tests never show the asked note's name, and "Name the note" runs show none.

          Data

          Everything is kept in this browser, in a DuckDB database per user, and copied to files on this computer by the local server (the data folder next to the app). If the browser loses its data, the app copies it back from those files on the next start. Export a JSON backup to move it to another device.
